# Python Virtual Environment Guide

This repository contains a simple HTML reference page for activating and deactivating Python virtual environments across Windows, macOS, and Linux.

## 🔗 Live Preview

Open the [live Python Virtual Environment Guide](https://mevorahde.github.io/venv_guide/) or open `index.html` in your browser.

## 📘 What's Inside

- Step-by-step commands for:
  - Windows CMD & PowerShell
  - macOS / Linux terminals
- Deactivation instructions
- Tips for package installation

## 💡 Usage

To use this page:
1. Clone or fork the repo.
2. Open `index.html` locally or use the live guide above.
3. Refer to it whenever you need a quick venv refresher.
